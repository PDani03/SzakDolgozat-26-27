# SzakDolgozat 2027
Kapitány Imre, Pomaházi Dániel, Oroszi Péter

Egy 2D-s C# játék, amit a Unityben készítünk. A GraveBound egy roguelite dungeon crawler, amiben egy hősies lélekként a grim reaper alkalmazottjaként dolgozunk, és azzal vezetjük vissza az elveszett lelkeket a sírjukhoz, hogy harcban legyőzzük őket, közben felszereléseket gyűjtve egy tetriszes hátizsák-rácsba.
